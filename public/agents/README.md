# Agent world sprites

These six field sprites were created with OpenAI's built-in Imagegen for the
Datehaja agent-dating prototype. They share a handcrafted, adult indie-game
pixel-art direction and are exported as transparent PNGs for the live world.

- `sprite-rose-v1.png`
- `sprite-violet-v1.png`
- `sprite-moss-v1.png`
- `sprite-sky-v1.png`
- `sprite-sunset-v1.png`
- `sprite-ink-v1.png`

The editable profile portrait remains vector-based so hair, expression, outfit,
and accessory controls stay functional. The world sprite is the agent's compact
field form and follows the selected color palette.
