## 1. 오래된 공개 데이트

새로 생성한 영어 서점 장면 데이트를 검토하고 **운영** 공개 기록으로 고정했다.
`showcase:publicDate`를 운영에서 직접 확인한 결과 `locale: en-US`, Juno/Sol의
16문장, 다섯 활동 기록과 독립적인 두 회고가 보존돼 있다. 마지막 문장은 작별
인사가 아니라 "한 페이지만 더" 제안으로 끝나며, 그 제안이 실행됐다는 기록은
없다. 두 회고 모두 `encourage`지만 소개를 강제하지는 않는다 — 실제 연결은
사람 두 명의 동의가 있어야 열린다. 무작위 최신 20건 검색에 의존하던 공개
선정을 검토된 기록의 내부 포인터로 보강했다.

완료·연속된 전체 대화·저널·두 회고가 없는 기록은 게시할 수 없다.
실제 참가자가 한 명이라도 포함되면 공개할 수 없다. 고정된 기록이
없어지거나 비공개로 바뀌면 다른 기록을 임의로 공개하지 않는다.
자세한 근거는 `bunx convex run --prod showcase:publicDate '{}'` 출력이다.
[새 공개 기록 검토](DEMO_REFRESH_REVIEW.md)는 그 이전 9월 11일 개발 기록을
다룬 문서이며, 지금 운영에 고정된 기록과는 다르다.

## 2. 독립적인 사용자 검증

**완료된 독립적인 체험: 0명.** 모집을 실행할 준비는 마쳤다.

- 한국어·영어 초대 초안, 설명 없는 첫 사용 과제, 진행자 기록 기준.
- 이름·이메일·비공개 대화를 받지 않는 [피드백 양식](https://merry-bass-190.convex.site/feedback).
- 응답 파일을 사용자가 직접 전달하는 구조. 이 페이지는 서버에 전송하지 않는다.
- 첫 데이트·피드백 저장·새 상대와의 다음 데이트가 모두 완료된 경우만
  전후 평가 대상으로 계산한다. 대기나 실패를 성공으로 세지 않는다.
- 중복 코드와 예상하지 않은 필드를 거부하는 집계 스크립트.

[체험 진행 문서](../submission/USER_STUDY.md)를 사용해 3–5명의 만 18세 이상
처음 쓰는 사람에게 체험을 진행해야 한다. 가상 인물과 자동화는 참가자가
아니다. 초대는 아직 보내지 않았다.

## 3. 영어 심사와 최신 제출 영상

[영어 학습 기록](https://merry-bass-190.convex.site/preview/agent-coaching?lang=en)에
네 데이트 56문장, 세 수정 요청, 실제 답장·누적 기억·저널·회고 전체의
번역을 추가했다. 한국어 원문과 기존 판정·근거 문장·해시는 유지했다.
존댓말 개선과 답변 길이가 줄지 않은 한계를 함께 표기한다.

[전체 시연](https://youtu.be/K35t6VaF0iI)(유튜브 일부공개)은 실제 브라우저 화면을
촬영한 **155초(2:35)** 영상이다. 저장된 가상 기록의 재생이고 시간 편집이
있음을 명시한다. 영어 자막은 영상에 포함되며 VTT와 대본도 제공한다. 내레이션은
화면에 나오는 자막을 그대로 읽으므로 소리를 꺼도 잃는 정보가 없다. 낭독본은
`submission/narration/`에 들어 있어 API 키 없이도 영상을 다시 만들 수 있고,
촬영본이 같은 기계에서는 동일한 SHA-256으로 재생성됐다. 촬영 디렉터리는
의도적으로 git 밖에 있으므로, 새로 클론한 곳에서는 다시 촬영해야 하고 그
프레임은 같은 해시가 되지 않는다. 기존 전체 영상을 교체하고 소셜 초안의 오래된 여섯 턴·무조건 소개
설명도 수정했다.
