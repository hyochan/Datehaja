# 제출 준비 상태 — 2026-09-11

세 가지 약점에 대응하는 코드·시연·검증 도구를 준비했다. 현재 확인 대상은
개발 **adorable-boar-359**다. 운영 **merry-bass-190**, 소셜 게시, 최종 제출,
독립적인 사용자 체험 결과까지 완료됐다는 뜻은 아니다.

## 1. 오래된 공개 데이트

새로 생성한 영어 갤러리 데이트를 검토하고 개발 공개 기록으로 고정했다.
Juno/Sol의 여섯 문장, 명시적인 작별, 네 활동 기록과 독립적인 두 회고를
보존했다. 결론은 둘 다 curious이며 소개를 강제하지 않았다. 무작위 최신
20건 검색에 의존하던 공개 선정을 검토된 기록의 내부 포인터로 보강했다.

완료·연속된 전체 대화·저널·두 회고가 없는 기록은 게시할 수 없다.
실제 참가자가 한 명이라도 포함되면 공개할 수 없다. 고정된 기록이
없어지거나 비공개로 바뀌면 다른 기록을 임의로 공개하지 않는다.
자세한 근거: [새 공개 기록 검토](DEMO_REFRESH_REVIEW.md).

## 2. 독립적인 사용자 검증

**완료된 독립적인 체험: 0명.** 모집을 실행할 준비는 마쳤다.

- 한국어·영어 초대 초안, 설명 없는 첫 사용 과제, 진행자 기록 기준.
- 이름·이메일·비공개 대화를 받지 않는 [피드백 양식](https://adorable-boar-359.convex.site/feedback).
- 응답 파일을 사용자가 직접 전달하는 구조. 이 페이지는 서버에 전송하지 않는다.
- 첫 데이트·피드백 저장·새 상대와의 다음 데이트가 모두 완료된 경우만
  전후 평가 대상으로 계산한다. 대기나 실패를 성공으로 세지 않는다.
- 중복 코드와 예상하지 않은 필드를 거부하는 집계 스크립트.

[체험 진행 문서](../submission/USER_STUDY.md)를 사용해 3–5명의 만 18세 이상
처음 쓰는 사람에게 체험을 진행해야 한다. 가상 인물과 자동화는 참가자가
아니다. 초대는 아직 보내지 않았다.

## 3. 영어 심사와 최신 제출 영상

[영어 학습 기록](https://adorable-boar-359.convex.site/preview/agent-coaching?lang=en)에

존댓말 개선과 답변 길이가 줄지 않은 한계를 함께 표기한다.

명시한다. 영어 자막은 영상에 포함되며 VTT와 대본도 제공한다. 기존 전체
영상을 교체하고 소셜 초안의 오래된 여섯 턴·무조건 소개 설명도 수정했다.

## 배포와 검증

운영 배포에는 PRODUCT_MEMORY.md의 정확한 대상 확인 규칙이 적용된다.
개발에서 백엔드 먼저, 프런트엔드 이후 배포하고 비로그인 /watch,
/preview/agent-coaching?lang=en, /demo, /feedback을 확인한다.
최종 실행 결과와 브라우저 검증은 [이번 변경 검토](DEMO_REFRESH_REVIEW.md)에 기록한다.

최종 제출에는 선택한 공개 URL·소스·영상의 버전 일치와 실제 게시 링크가
필요하다. 현재 개발 후보를 제출 대상으로 삼을 수도 있으나, 기존 제출
초안은 운영 URL을 사용하므로 게시 전 승인된 배포와 링크를 맞춰야 한다.
우승 확률이나 실제 사용자 만족도는 이 검증만으로 추정하지 않는다.
